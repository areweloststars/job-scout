# 다음 단계 계획: 장별 논점 × 이미지

목표: 각 장을 저자의 논점별로 나누고, 논점마다 **제목 → 장면 이미지 → 설명 + 관찰 가설** 순서로 보여 주기.
근거: 대한성서공회 개역개정 소제목·각주, 헬라어 SBLGNT(NA28과 거의 같음), 구약 인용은 히브리어 WLC.

## 현재 상태 (완료)
- 16장을 개역개정 소제목 기준 논점 115개로 나눔. 논점마다 제목 → 그림 → 핵심 구절 → 설명 → 관찰 가설 → 나에게 순서로 표시 (`points.js`)
- 그림은 모두 퍼블릭 도메인(CC0 포함). 티소 그림은 브루클린 미술관 원본, 그 밖은 메트로폴리탄 미술관 Open Access, 미국 의회도서관, 위키미디어 공용
- 인용은 개역개정, 헬라어는 SBLGNT, 히브리어는 WLC와 스크립트로 대조
- 장마다 읽는 시간을 분당 475자로 자동 계산 (약 4~9분)
- 아티팩트: https://claude.ai/artifact/3joQGgqopk3RHkes8hmSwD

## 이미지
- 대부분 제임스 티소 〈예수의 생애〉(브루클린 미술관, 퍼블릭 도메인). 위키미디어 파일명: `docs/tissot-map.json`
- 티소에 없는 장면은 브뤼헐, 뒤러, 반 에이크, 도메니키노 등 퍼블릭 도메인 작품으로 채움. 출처는 페이지 맨 아래 ‘그 밖의 그림 출처’
- CC BY, CC BY-SA처럼 출처 표시나 동일 조건이 필요한 사진은 쓰지 않음

## 남은 작업
- 요점 설명과 쉬운 번역을 읽어 보고 다듬기
- 관찰 가설 항목은 사용자 요청으로 페이지에서 뺌

## 완료 기록
- 요점마다 ‘본문 펼치기’로 성경 본문을 직접 실음. 쉬운성경은 저작권이 있어 헬라어 원문(SBLGNT)을 쉬운 우리말로 새로 옮김 (1–16장 673절, `tools/points/tx1.py`–`tx5.py`)
- 디자인 개편: 속표지 그림과 펼친 책장, 고운바탕·송명 글꼴, 기본은 밝은 종이 화면이고 ‘밤에 읽기’ 버튼으로 어두운 화면 선택
- 요점마다 그림 아래에 호기심을 여는 질문 추가 (`tools/points/asks.py`), ‘재미있게 읽는 방법’ 부분은 사용자 요청으로 뺌
